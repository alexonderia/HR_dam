# Исправление профессионального стажа и оценок: evidence-v5

Дата: 20 ноября 2026 года. Модель остаётся `qwen3.5:2b-q4_K_M`.

## Что было неправильно

У Валиева профиль Backend получил 52,94 балла: 35,29 за общий период работы в транспорте и 17,65 за высшее образование. Python, SQL и REST API не были подтверждены. Причина — общее условие «от 3 лет» не имело профессиональной области.

У руководителя производственного подразделения часть подтверждающих цитат попала в `not_met`. Валидация не проверяла смысл отрицательного решения для нечислового опыта. Кроме того, запятые дробили обязанности и образование, а похожие названия должностей считались отдельными обязательными навыками.

«Начальник автоколонны» с 47,06 балла относится к старому неактивному демо-кластеру и политике v2. Это отдельный исторический результат.

## Изменения

- Общее числовое требование стажа получает `experience_scope`: должность и профессиональные признаки профиля. Периоды другой работы его не подтверждают.
- При описанном повышении весь срок компании не считается стажем последней руководящей роли. Нужны подтверждения периода именно этой роли.
- Один переносимый инструмент (например SQL в транспортной компании) не подтверждает годы Backend: проверяется должность либо полный профессиональный набор в той же работе.
- Общий стаж по датам работы сохраняется отдельно от профессионального и показывается с пояснением.
- Если нет подтверждённого обязательного профессионального условия, общий диплом и стаж не повышают основной балл. Подтверждённое образование сохраняется фактом. Результат означает отсутствие доказательств соответствия, а не доказанную неспособность кандидата.
- Проверяются положительные и отрицательные выводы для опыта, образования, навыков и дополнительных требований. Достаточная прямая цитата исправляет ошибочную полярность. Противоречия остаются на уточнении.
- Для перефразированных обязанностей сохраняется ограниченная смысловая проверка. Она не может отменять отрицание, числовую область, требования самостоятельности и точность цитат.
- Запятые внутри обязанности или оговорки больше не создают самостоятельных требований. «Или» означает альтернативы, «и» — необходимые части; непонятная смешанная логика требует уточнения.
- В текущем профиле руководителя пять похожих названий должности объединены через «или», разорванный стоп-фактор соединён. Остальные условия сохранены.
- Профессиональные признаки из самого профиля ограничивают перенос обязанностей: организация транспортной колонны не подтверждает строительство или реконструкцию объектов. Для неоднозначного совпадения сохраняется уточнение.
- API независимо проверяет компиляцию требований, цитаты, области стажа, статусы и арифметику. Политики v1–v4 читаются прежними правилами.
- Миграция V8 добавляет `resume_rating_history`: предыдущие оценки и снимки требований сохраняются в транзакции перед заменой. Повторное применение одного задания не создаёт вторую архивную запись.
- Неактивные кластеры отмечены как архивные, у профилей показана дата оценки. В обработку попадают только активные требования.

## Проверки

156 тестов Python, 138 тестов TypeScript и 7 тестов расчёта метрик качества. Общие синтетические фикстуры v5 проверены независимым валидатором API. Старые фикстуры v4 сохранены и продолжают проходить проверку.

Проверены реальный PDF по всем текущим профилям без модели, сборка пяти контейнеров, миграция V8, изоляция сервисов и Compose. Браузерная проверка подтверждает пояснение нулевого профессионального соответствия, отдельный общий стаж и отображение отчёта на ширине 390 и 1280 пикселей.

Синтетические регрессии проверяют логику, а не точность модели на независимой выборке. Процент качества классификации без HR-разметки не заявляется.

При повторяющихся или пропущенных ID модельный запрос автоматически дробится на меньшие группы с общим дедлайном. Неполный ответ не принимается как результат.

Модель также может пропускать перефразированные обязанности; независимая проверка HR по-прежнему необходима для оценки качества извлечения.
