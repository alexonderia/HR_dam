# Удаление версии из контрактов и приложения

Дата: 9 ноября 2026 года.

## Изменения

- Внутренние адреса обработчиков: `/internal/guest/jobs/...` и
  `/internal/app/jobs/...`, без промежуточного `/v2`.
- Обменники: `hr.processing`, `hr.processing.events`, `hr.processing.dead`.
  Очереди: `hr.<guest|authorized>.<prepare|evaluate|events|dead>`, без суффикса.
  Настройки маршрутизации, прав и политик обновлены согласованно.
- Из команд и событий удалено поле `schema_version`; схема по-прежнему
  отклоняет неизвестные поля. ID, номера попыток и токены задания сохранены.
- Таблицы обработки называются `processing_tasks` и `processing_outbox`.
  Миграция V8 сохраняет строки, связи, ID и неподтверждённые публикации,
  удаляя прежнее поле версии из сохранённых заданий и сообщений.
- История миграций, включая уже применённую V7, не переписывалась.
- Модуль backend переименован в `processing-service.ts`, тесты и фикстуры
  используют имена `processing`/`processing-contract`, команда проверки —
  `npm run test:processing`. Временный тестовый проект имеет имя
  `hr-dam-processing-qa`.
- Контракт `docs/processing-services-contract.md`, инструкция
  `docs/preparation.md`, конфигурация и ссылки соответствуют реализации.

## Проверки

- `npm run build`, `npm test` — успешно, 80 тестов.
- `npm run test:architecture`, проверка Compose и `git diff --check` — успешно.
- V8 проверена на синтетических данных старого формата в отдельной схеме
  PostgreSQL с последующим откатом тестовой транзакции: строки, ID и намерение
  публикации сохранены, поле версии удалено.
- Сквозная проверка в изолированном стенде прошла с настоящими RabbitMQ и S3:
  два режима, права, разбор → оценка, несколько выходов ZIP, частичный отчёт,
  повторы и DLQ, восстановление outbox после перезапуска, удаление гостевых
  данных, авторизация и браузерный интерфейс.
- В проверке использованы синтетические обработчики протокола и транспортный
  stub антивируса. Реальные разборщик и оценщик остаются в другой ветке.

Для временного стенда выделены небольшие подсети: стандартный пул Docker
оказался исчерпан. После проверки его контейнеры, тома, сети и четыре тега
образов удалены. Другие проекты не затрагивались.

## Основной стенд

Перед переключением остановлены приём запросов и API обработки, сделаны копии
PostgreSQL и конфигурации RabbitMQ. Старые очереди проверены повторно:
сообщений и потребителей не было. Применена V8, создана новая топология,
удалены старые пустые очереди, обменники и политика обработки.

Пересобраны и пересозданы backend, guest-api и frontend. Использованы
существующие локальные runtime-образы и новая проверенная сборка; версии
зависимостей не менялись. Остальные пять основных контейнеров не пересоздавались.
