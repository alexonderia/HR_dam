# Отступы гостевой формы и выбор файлов

Исправлено 9 ноября 2026 года по предоставленным снимкам экрана.

- Гостевой экран использует отдельный корень `af guest-app`: сбросы отступов
  заголовков и padding из рабочего кабинета больше на него не влияют.
- Шапка, вводный текст и форма выровнены по общей ширине 960 px. Отступы заданы
  токенами Framework. Парные критерии размещены в двух колонках на широком
  экране и в одной колонке на телефоне.
- Название подбора использует `af-input--lg`, многострочные критерии —
  `af-textarea`, карточки — `af-card--outer`. Геометрия компонентов берётся
  из Alabuga 1.3.1; файлы самой библиотеки не изменялись.
- Стандартный файловый input заменён кнопкой `af-btn--secondary` с иконкой
  прикрепления. Сохранён нативный выбор нескольких файлов; показаны имена,
  размеры и общий объём, доступны удаление и повторный выбор. Во время
  отправки изменение списка заблокировано.
- В диалоге применены слоты заголовка Framework и штатная кнопка с иконкой.
  Окно входа ограничено шириной 440 px; добавлены промежутки между полями и
  действием. Неверный пароль больше не запускает сброс сессии, который раньше
  скрывал сообщение об ошибке; остальные ответы 401 обрабатываются как прежде.

Проверки: production-сборка с TypeScript, шесть рабочих разделов после изменения
общих компонентов, гостевой экран и вход на ширинах 1440, 1024, 390 и 320 px.
Проверены открытие выбора файлов с клавиатуры, удаление и повторный выбор,
перенос длинных имён, блокировка во время отправки, передача двух файлов и
критериев в multipart-запросе и отображение ошибки входа. Ошибок JavaScript
и горизонтального переполнения страницы не обнаружено.

После развёртывания повторены проверки гостевого интерфейса. `/api/session`
проверялся через настоящий сервис; вход и отправка файлов использовали ответы
API в браузере. Проверки не создавали пользователей и задачи в основной БД.

Пересобран образ и пересоздан только frontend `hr_dam`; остальные семь
контейнеров сохранили ID. Все восемь сервисов healthy, `/health` — 200.
Использован имеющийся локальный runtime и проверенная production-сборка:
доступ к Docker Hub в текущей среде ограничен ошибкой DNS, выявленной ранее.

`preview-checks.json`, `deployed-checks.json`, `runtime-checks.json` и лог
Docker-сборки. Предыдущий образ сохранён как
`hr-dam-frontend:before-guest-layout-20261109`.
